# mindcode

Helps the agent write and edit marketing copy that reads like a person wrote
it. It covers page copy, editing passes on existing copy, removing AI writing
tells, and advertising fundamentals such as positioning, the promise and
headlines.

## Install

```
/plugin marketplace add mind-code-ai/mind-plugins-official
/plugin install mindcode@mind-plugins-official
```

## Skills

The agent picks these up by itself when a request matches. You can also invoke
them directly:

| Skill | Use it for |
| --- | --- |
| `/mindcode:copywriting` | Writing or rewriting copy for homepages, landing, pricing, feature and about pages: headlines, CTAs, value propositions |
| `/mindcode:copy-editing` | Systematic editing passes on existing copy, and refreshing outdated content |
| `/mindcode:humanizer` | Rewriting AI-sounding prose so it reads like the writer without changing what it says |
| `/mindcode:advertising-principles` | Positioning, the single promise, the big idea, headline and body-copy rules for ads and persuasive text |
